# EC MASTER SALES ONE-PAGER INSTRUCTIONS

**Version 2.0**

------------------------------------------------------------------------

# Purpose

This document defines the standards for creating Evolving Consulting
Sales One-Pagers.

The goal is to produce executive-quality documents that help the sales
team communicate business value quickly and professionally.

These one-pagers are intended for:

-   Account-Based Marketing (ABM)
-   Industry-specific collateral
-   Executive leave-behinds
-   Discovery meeting material
-   Salesforce solution overviews
-   Client follow-up
-   Conference material
-   Sales enablement

Every document must feel like it belongs to the same design system as
all EC proposals, project kick-offs, change orders, project snapshots,
invoices, service agreements, and executive documentation.

------------------------------------------------------------------------

# Overall Design Philosophy

Every one-pager should communicate:

-   Business first
-   Technology second
-   Executive audience
-   Clean and modern
-   Minimalistic
-   Premium consulting firm
-   Plenty of white space
-   Large typography
-   Easy to scan in under 60 seconds

Avoid marketing fluff.

Avoid buzzwords.

Write as an advisor, not as a salesperson.

------------------------------------------------------------------------

# Page Format

-   Portrait
-   Letter Size
-   Single page only.
-   Never overflow to a second page.

# Iconography Standards

Icons are part of the EC design language.

## Style

-   Thin outline
-   Black only (#111111)
-   Transparent background
-   No fills
-   No gradients
-   No shadows
-   Modern enterprise appearance
-   Geometric line art

## Stroke

-   Uniform 1.5--2px equivalent

## Preferred Style

Match the appearance of:

-   Lucide
-   Tabler
-   Feather
-   Material Symbols (Outlined)

## Sizes

-   Small: 22px
-   Medium: 26px
-   Large: 32--36px

## Business-first Icons

Examples:

-   Sales → Pipeline
-   Customer → People
-   Finance → Invoice
-   Analytics → Dashboard
-   Automation → Workflow
-   Integration → Connected Nodes
-   AI → Spark
-   Projects → Kanban
-   Support → Headset
-   Documents → File

## AI Prompt

> Minimal enterprise outline icon, thin black strokes, transparent
> background, no fill, no gradients, no shadows, geometric line-art,
> matching Lucide/Tabler style, suitable for executive consulting
> documents.

## Validation

-   Same icon family throughout document.
-   Same stroke width.
-   Transparent background.
-   Black only.
-   No mixed icon styles.

# Generation Workflow

1.  Understand audience.
2.  Identify business objective.
3.  Build the narrative.
4.  Select the best layout components.
5.  Maintain generous whitespace.
6.  Use only relevant Salesforce products.
7.  Apply EC iconography standards.
8.  Produce production-ready HTML for DocGen/PDF.
